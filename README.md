# Publish with GitHub Pages

Repository name: `jarvis-content-studio`

Upload every file in this folder to the repository root, then open:

1. Settings
2. Pages
3. Build and deployment → Deploy from a branch
4. Branch → `main`, folder → `/ (root)`
5. Save

Expected URLs:

- Website: https://Soramame1192.github.io/jarvis-content-studio/
- Terms: https://Soramame1192.github.io/jarvis-content-studio/terms.html
- Privacy: https://Soramame1192.github.io/jarvis-content-studio/privacy.html
